# School calendar

Every Monday this builds `school.ics` from the Gosforth Park First School
website calendar, keeping Reception and Year 4 events plus school-wide dates.

Subscribe on iPhone: Settings → Apps → Calendar → Calendar Accounts → Add Account →
Other → Add Subscribed Calendar, and paste:

    https://raw.githubusercontent.com/stocknewsanalysis/school-calendar/main/school.ics

To update now: Actions tab → "Update school calendar" → Run workflow.
